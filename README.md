# pingmask

Ping and reshape mask text streams with deterministic transforms.

**Site:** https://theworker02.github.io/pingmask/

## Install / run

```bash
git clone https://github.com/theworker02/pingmask.git
cd pingmask
node src/cli.js
node --test
```
